Distill

AI reading interface

Project 07

Distill is an AI reading interface. It takes an article or pasted text and turns it into hierarchical, sectioned summaries, presented in a three-pane reading layout. The summaries are produced through the OpenAI API, and the interface preserves the original's footnotes and references. It is built on the Next.js App Router with TypeScript.

Role: Self-directed project

Type: AI reading interface

Stack: Next.js App Router, TypeScript, OpenAI API

What was built

  • A pipeline that turns an article or pasted text into hierarchical, sectioned summaries.
  • Summary generation through the OpenAI API.
  • A three-pane reading layout for the source text and its summary.
  • Footnotes and references preserved from the original text.
  • A Next.js App Router application written in TypeScript.

Distill's three-pane layout: the source text, the sectioned summary produced from it, and the footnotes and references the reading view keeps in place.

Live at distill-mu.vercel.app; the project's own domain, distill.wiki, also responds. Both checked 2026-09-28.

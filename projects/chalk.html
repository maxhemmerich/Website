Chalk

Chalk is an SMS habit tracker. You text a habit to it each day, and it tracks those habits on a live dashboard. The backend is a Node.js and Express service that handles Twilio SMS webhooks and runs the cron scheduling behind the daily prompt; the dashboard is a React and Vite app that reads Supabase with realtime updates, and the database behind it is Supabase on Postgres.

Role

Self-directed project

Type

SMS habit tracker

Stack

Node.js, Express, Twilio, React, Vite, Supabase

What was built

  • A Node.js and Express backend that receives habit messages through Twilio SMS webhooks.
  • Cron scheduling that drives the daily habit prompt.
  • A React dashboard, built with Vite.
  • Supabase on Postgres as the database behind the dashboard.
  • Realtime updates, so the dashboard follows the database as the habits arrive.

Live at chalk-seven.vercel.app — checked 2026-09-28.

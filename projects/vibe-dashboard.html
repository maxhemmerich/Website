VIBE Dashboard

This dashboard consolidated recruitment and study-performance monitoring into a self-serve interface for leadership. It was built independently within CAMH research operations as a multi-tab HTML dashboard using CAMH branding standards, and it translated operational questions into visible metrics for conversion, velocity, retention and recruitment bottlenecks.

Facts

Role: Built independently within CAMH research operations

Type: Internal dashboard / operational reporting

Stack: HTML, CSS, recruitment funnel design, KPI definition

No public link

What I built

  • Built and independently shipped a multi-tab HTML dashboard using CAMH branding standards.
  • Defined operational KPIs for recruitment funnel monitoring.
  • Tracked conversion, velocity, retention, and participant drop-off patterns.
  • Structured the interface for non-technical leadership use.

Why it mattered

  • Improved visibility into recruitment performance.
  • Reduced dependence on ad hoc reporting requests.
  • Made study bottlenecks easier to identify and discuss.
  • Supported leadership with self-serve monitoring instead of manual updates.
